APD -- ARS Packet Description language
======================================

APD is the text language used to describe TCP/IP packets for the ARS
engine: the styxwire command line (--apd-send, --dry-run) and the Tcl
commands (styxwire send / build / describe / validate). This document
matches the implementation in apd.c and rapd.c; the syntax changed from
the very old hping documentation (see "History" at the end).

GENERAL FORMAT
~~~~~~~~~~~~~~

  A packet is a sequence of layers joined with "+":

	layer(field=value,field=value,...)+layer(...)+...

  Fields are enclosed in parentheses "()", separated by commas, and given
  as field=value. A layer with no explicit field is written with empty
  parentheses, e.g. icmp() or ip.nop(). Example:

	ip(daddr=192.168.1.2)+udp(sport=53,dport=53)+data(file=./dns.packet)

  You do not need to specify fields ARS can compute: checksums, header
  lengths, the IP total length, the protocol field and option padding are
  generated during compilation unless you set them explicitly. Setting one
  of them by hand (for example cksum=...) keeps your value, so you can
  build deliberately wrong packets.

  A layer may be followed by "+", by a decimal length that truncates it,
  or by the end of the string. The length form is rarely needed.

  Numeric values are decimal, 0x-prefixed hex or 0-prefixed octal
  (10 == 0xA == 012). IP addresses are dotted quads or host names.

LAYERS
~~~~~~

  ip            IP header
  ip.eol        IP option: End of option list
  ip.nop        IP option: No operation
  ip.sec        IP option: Security
  ip.sid        IP option: Stream ID
  ip.lsrr       IP option: Loose Source and Record Route
  ip.ssrr       IP option: Strict Source and Record Route
  ip.rr         IP option: Record Route
  ip.ts         IP option: Timestamp
  udp           UDP header
  tcp           TCP header
  tcp.eol       TCP option: End of option list
  tcp.nop       TCP option: No operation
  tcp.mss       TCP option: Maximum Segment Size
  tcp.wscale    TCP option: Window Scale
  tcp.sackperm  TCP option: SACK permitted
  tcp.sack      TCP option: Selective ACK
  tcp.echo      TCP option: Echo request  (alias: tcp.echoreq)
  tcp.echoreply TCP option: Echo reply
  tcp.ts        TCP option: Timestamp     (alias: tcp.timestamp)
  icmp          ICMP header
  ip6           IPv6 header
  icmp6         ICMPv6 header
  igrp          IGRP header
  igrp.entry    IGRP entry
  data          Generic data

  Aliases exist so that a description produced by "styxwire describe" (or
  the Tcl "hping describe" / rapd) parses back unchanged; the canonical
  name written by describe is tcp.echo and tcp.ts.

FIELDS
~~~~~~

  IP (ip):
    saddr daddr           address (dotted quad or host name)
    ihl ver tos totlen    numeric header fields
    id fragoff            numeric
    mf df rf              0 or 1 (more-fragments, dont-fragment, reserved)
    ttl proto cksum       numeric (proto also accepts icmp/udp/tcp)

  UDP (udp):
    sport dport len cksum numeric

  TCP (tcp):
    sport dport seq ack   numeric
    x2 off win urp cksum  numeric
    flags                 any of the letters F S R P A U X Y (e.g. flags=sa)

  ICMP (icmp):
    type code cksum       numeric
    id seq                numeric (echo id / sequence)
    gw                    address (redirect gateway)
    unused                numeric (the 32-bit id/seq/gw word)

  IPv6 (ip6):
    saddr daddr           address (IPv6 literal or host name)
    ver tclass flow       version nibble, traffic class, flow label
    plen                  payload length (computed when not given)
    nh (alias nexthdr)    next header; also accepts icmp6/tcp/udp/none
    hlim (alias hoplimit) hop limit (default 64)
    There is no cksum field: IPv6 has no header checksum. TCP and UDP
    below an ip6 layer use the RFC 8200 8.1 pseudo-header.

  ICMPv6 (icmp6):
    type code cksum       numeric (128 echo request, 129 echo reply)
    id seq                numeric (echo id / sequence)
    unused                numeric (the 32-bit unused word of the errors)
    The checksum covers the IPv6 pseudo-header (RFC 4443 2.3), unlike
    ICMPv4's. See docs/IPV6.txt for what is and is not supported.

  DATA (data), one field per layer:
    file=PATH             raw bytes read from a file
    str=TEXT              a string; a backslash followed by two hex digits
                          is one byte (e.g. "a\41b" is "aAb"), any other
                          backslash is literal
    hex=HEXDIGITS         raw bytes as hex (even number of digits)
    uint32 uint24 uint16 uint8 = N   an integer of that width, big endian

  IP options:
    ip.sec:   optlen seclev comp hrest(4 hex) tcc(6 hex)
    ip.sid:   optlen sid
    ip.rr / ip.lsrr / ip.ssrr:
              optlen ptr data=IP1/IP2/...   (slash-separated addresses)
    ip.ts:    optlen ptr overflow
              flags=tsonly|tsandaddr|prespec (or a number)
              data=TS/TS/...            (tsonly)
              data=TS@GW/TS@GW/...      (tsandaddr / prespec)

  TCP options:
    tcp.mss:      optlen size
    tcp.wscale:   optlen shift
    tcp.sack:     optlen blocks=ORIG-LEN/ORIG-LEN/...   (max 4 blocks)
    tcp.echo / tcp.echoreply: optlen info
    tcp.ts:       optlen val (=tsval) ecr (=tsecr)

  IGRP (igrp):
    version edition autosys interior system exterior cksum
    opcode=update|request (or a number)
  IGRP entry (igrp.entry):
    dest=A.B.C delay bandwidth mtu reliability load hopcount

  The eol/nop options and sackperm take no field other than the optional
  optlen.

EXAMPLES
~~~~~~~~

  # ICMP echo request with a payload
  ip(saddr=1.2.3.4,daddr=192.168.1.1)+icmp(type=8,code=0)+data(str=hello)

  # ICMP port unreachable quoting a UDP packet
  ip(saddr=1.2.3.4,daddr=5.6.7.8)+icmp(type=3,code=3)\
  +ip(saddr=5.6.7.8,daddr=1.2.3.4)+udp(sport=53,dport=53)

  # TCP SYN with MSS and timestamp options (options are padded to a
  # 4-byte boundary automatically)
  ip(daddr=5.6.7.8)+tcp(dport=80,flags=s)+tcp.mss(size=1460)+tcp.ts(val=1,ecr=0)

  # a deliberately wrong IP checksum (kept because it is explicit)
  # ICMPv6 echo request (offline only: the command line sends IPv4)
  ip6(saddr=2001:db8::1,daddr=2001:db8::2)+icmp6(type=128,id=7,seq=1)+data(str=hi)

  # TCP SYN over IPv6; the checksum uses the IPv6 pseudo-header
  ip6(daddr=2001:db8::2)+tcp(sport=1234,dport=80,flags=s)

  ip(daddr=5.6.7.8,cksum=0x0000)+tcp(dport=80,flags=s)

  Command line:  styxwire --dry-run --apd-send 'ip(daddr=127.0.0.1)+icmp()'
  Tcl:           set pkt [styxwire build {ip(daddr=127.0.0.1)+icmp()}]
                 styxwire describe $pkt

HISTORY
~~~~~~~

  The original hping documentation described the syntax with braces
  (ip{...}) and prefixed the options ipopt.* / tcpopt.*. The engine has
  always used parentheses and the ip.* / tcp.* names shown here; the
  braces form never worked. tcp.echoreq and tcp.timestamp are accepted as
  aliases for tcp.echo and tcp.ts.
